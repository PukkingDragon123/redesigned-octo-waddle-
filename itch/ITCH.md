# SKYSONG on itch.io

## Files in this folder

| File | Use |
|---|---|
| `skysong-html5.zip` | Upload as the game: Kind of project **HTML**, and tick **"This file will be played in the browser"**. `index.html` is at the root of the zip. |
| `skysong-cover-630x500.gif` | Cover image: animated, the whale's song forms the title. This is itch.io's recommended cover size. |
| `skysong-cover-315x250.gif` | A lighter cover, if the full-size GIF is too heavy for the upload. |
| `skysong-cover-630x500.png` | A still cover, if a GIF isn't wanted. |
| `skysong-banner-1920x600.png` | Page banner: the herd flying into the sunset. |
| `skysong-banner-1920x600-notitle.png` | The same banner without the lettering. |

## Embed settings

- **Viewport dimensions:** 960 × 540. Tick **Mobile friendly** (touch works) and **Fullscreen button**. **Automatically start on page load** can stay off; the game starts from its own title menu.
- **SharedArrayBuffer support:** not needed.
- **Sound:** the game asks for a click before any sound, as browsers require.

## Short description

> A wordless film you play: the whole life of a flying whale on the ocean planet Vur Sok. Hatch in a
> whirlpool, follow your mother, eat, learn your voice, survive the storm, find a mate, guard your own
> egg, and rest as the elder of the herd.
